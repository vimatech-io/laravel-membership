# Contributing

Thank you for considering contributing to `laravel-membership`!

## Requirements

- PHP 8.3+
- Composer

## Setup

```bash
git clone https://github.com/vimatech/laravel-membership.git
cd laravel-membership
composer install
```

## Tests

```bash
composer test
```

## Code Style

This project uses [Laravel Pint](https://laravel.com/docs/pint) for code formatting:

```bash
composer format
```

## Static Analysis

```bash
composer analyse
```

## Pull Requests

1. Fork the repository
2. Create a branch: `git checkout -b feat/your-feature`
3. Make your changes and add tests
4. Ensure all tests pass and code is formatted
5. Submit a pull request

Please keep PRs focused — one feature or fix per PR.
